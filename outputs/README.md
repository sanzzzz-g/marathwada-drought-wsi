## Data Partitions & Forecast Semantics

### Chronological Splits
- **Training Set**: `2003-01-01` to `2017-12-01` (180 months $\times$ 8 districts = **1,440 rows**, 68.18%)
- **Validation Set**: `2018-01-01` to `2020-12-01` (36 months $\times$ 8 districts = **288 rows**, 13.64%)
- **Test Set**: `2021-01-01` to `2024-12-01` (48 months $\times$ 8 districts = **384 rows**, 18.18%)

### Multi-Step Forecast Origin Bounds ($H = 3$ months)
- **Input Tensor**: 12-month lookback window $[t-11, \dots, t]$ across 6 standardized stress components: shape $(12, 6)$.
- **Forecast Targets**: Continuous WSI values for $[t+1, t+2, t+3]$: shape $(3,)$.
- **Training Origins**: `2003-01-01` through `2017-09-01`. The final training origin `2017-09-01` targets October, November, and December 2017, completely contained within the training partition.
- **Validation Origins**: `2018-01-01` through `2020-09-01`. Zero target leakage from training into validation.
- **Test Origins**: `2021-01-01` through `2024-09-01`. Zero target leakage from validation into test.

## WSI Mathematical Formulation

The Water Stress Index is an equal-weighted composite metric:

$$\text{WSI}_{d, t} = \frac{1}{6} \sum_{k=1}^6 z_{d, t}^{(k)}$$

where all $z^{(k)}$ are calibrated such that **positive values indicate drought stress** and **negative values indicate surplus water**:

1. $z_{\text{spi}} = -\frac{\text{SPI}_3 - \mu_{\text{train}}}{\sigma_{\text{train}}}$
2. $z_{\text{soil}} = -\frac{\text{SoilAnomaly} - \mu_{\text{train}}}{\sigma_{\text{train}}}$
3. $z_{\text{ndvi}} = -\frac{\text{NDVIAnomaly} - \mu_{\text{train}}}{\sigma_{\text{train}}}$
4. $z_{\text{lst}} = +\frac{\text{LSTAnomaly} - \mu_{\text{train}}}{\sigma_{\text{train}}}$
5. $z_{\text{gw}} = +\frac{\text{GWAnomaly}_{\text{obs}} - \mu_{\text{asof, train}}}{\sigma_{\text{asof, train}}}$
6. $z_{\text{sw}} = -\frac{\text{SWAnomaly} - \mu_{\text{train}}}{\sigma_{\text{train}}}$

### Classification Categories

| Category | WSI Range | Physical Condition |
| :--- | :--- | :--- |
| **Very Wet** | $\text{WSI} < -1.5$ | Extreme moisture surplus / flood risk |
| **Wet** | $-1.5 \le \text{WSI} < -0.5$ | Above-normal moisture availability |
| **Normal** | $-0.5 \le \text{WSI} < 0.5$ | Near-climatological average conditions |
| **Moderate Stress** | $0.5 \le \text{WSI} < 1.5$ | Significant moisture and hydrological deficit |
| **Severe Stress** | $\text{WSI} \ge 1.5$ | Severe hydrological and agricultural drought |
